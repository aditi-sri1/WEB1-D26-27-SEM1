Web Designing

HTML is the standard markup language forcreating web pages.

Parts in web designing

There are three main parts in web designing:

  • HTML
  • CSS
  • JavaScript

HTML

HTML is the standard markup language for creating web pages.

CSS

CSS is used to control the style and layout of web pages.

JavaScript

JavaScript is a programming language that allows you to create dynamic content on web pages.

Types of Lists in HTML

There are three types of lists in HTML:

  1. Ordered List
  2. Unordered List
  3. Description List

Tags in HTML

HTML tags are used to create elements on a web page. There are two types of HTML tags:

  • Self-closing tags
    1. img
    2. br
    3. hr
  • Container tags
    1. p
    2. h1, h2, h3, h4, h5, h6
    3. div
